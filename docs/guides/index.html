Pre-alpha · 1 player · Linux

Your games, on Linux, with nothing left behind.

>veneer set sekiro display=gamescope upscaling=fsr

Veneer finds your Steam library and the games you add yourself, and runs them through Proton, Wine or natively, with gamescope and OptiScaler one click away. Everything it adds is layered over the game at launch and gone when the game exits.

High scores

RankWhy Veneer
1ST Game files are never touched.

OptiScaler's usual install copies DLLs into the game directory, where an update or a file check can break it. Veneer mounts them in an overlay only the game sees, so the install stays as Steam left it.

2ND Three choices per game.

Runner, Display and Upscaling, each with a working default. The rest is detected, or tucked under Advanced.

3RD Warnings before launch, not after a crash.

Whether gamescope or OptiScaler works depends on the GPU, the kernel and the driver. Veneer checks them and says why a launch would fail, and how to fix it, before you press Play.

4TH Every feature works without the window.

veneer list, veneer run, veneer set and veneer doctor do from a terminal what the window does.
